# agentic-brand rules

These rules bind every run of `agentic-brand`. They also bind agents
that drive this pack over MCP.

1. Validate the brand kit before rendering or checking voice.
2. Preview before you act. Run each dispatch with dry run first.
3. Respect guards. A denied call stays denied.
4. Report failures as failures. Adapters throw, and callers surface
   the error. No silent success follows a failed call.
5. Count the cost. Read the cost report before you close a task.
6. Keep quiet hours. The pack refuses routes inside the window.

Pack: Brand-kit validator for voice, look, and templates. Keywords:
brand-kit, voice, templates, agentic-suite, claude-code, codex, cli, mcp.
